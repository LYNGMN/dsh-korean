# dsh-git-stage

DeepSeek Harness(DSH) Desktop 대화 머리의 보기 탭(`채팅 · 실행 흐름 · …`)에 **작업 단계** 보기를 더하는 플러그인입니다. DeepSeek 공식 플러그인이 아닙니다. 그 세션 작업 폴더의 Git 상태를 읽어, 일이 아래 여섯 단계 가운데 어디쯤인지와 다음에 무엇을 승인해야 하는지 보여 줍니다.

| 단계 | 쉬운 뜻 | 끝남으로 보는 때 |
|---|---|---|
| 1 작업실 | 원본(`main`)은 두고 일마다 따로 여는 작업선(브랜치) | 기본 브랜치가 아닌 브랜치에 있음 |
| 2 고치고 저장 | "여기까지 저장" 도장(커밋). 아직 GitHub에는 없음 | 저장 안 된 변경 0개, 원본보다 앞선 커밋 1개 이상 |
| 3 검증 | 테스트·화면 확인 | 세션이 이 저장소에서 돌린 테스트·빌드가 통과했고 그 뒤에 고친 파일이 없음(실행 기록이 없으면 할 일 목록의 검증 항목 완료) |
| 4 공유(푸시·PR) | GitHub에 올리고 "합쳐도 될까요?" 검토 요청 | 올리지 않은 커밋 0개 |
| 5 합치기(머지) | 검토 끝난 변경을 원본에 반영 | PR이 머지됨 |
| 6 배포 | 실제 서비스에 반영(머지와 별개). Wrangler·`npm run deploy`·태그 가운데 그 저장소 방식으로 말함 | 그 커밋을 담은 `v*` 태그가 있음 |

- **지금 카드**: 맨 위에 지금 단계의 에이전트가 하는 일·상태·올라가는 것·다음 할 일·요청 문장을 모읍니다. 공유·합치기·배포가 지금 단계면 "승인 필요", PR 검사가 실패하면 "검사 실패", 에이전트가 일하는 중이면 "에이전트 작업 중" 배지가 붙습니다.
- **단계 줄**: 여섯 칸을 누르면 아래에 그 단계의 쉬운 뜻과 상태가 펼쳐집니다.
- **승인 전에 올라가는 것**: 공유·합치기 단계에서 이번에 올라갈 저장 기록 제목(최대 20개)과 바뀐 파일·줄 수를 보여 줍니다. 저장 안 된 변경은 "올라가지 않아요"로 따로 접어 둡니다.
- **이렇게 요청해 보세요**: 지금 단계에서 에이전트에게 보낼 만한 요청(예: "테스트와 빌드를 돌리고, 통과하면 푸시해서 검토 요청(PR)을 초안으로 열어 주세요. PR 본문에는 바뀌는 것·확인한 것·확인하지 못한 것을 적어 주세요.")을 보여 줍니다. "입력창에 넣기"를 누르면 입력창 커서 자리에 넣기만 하고, 보내기는 사람이 직접 누릅니다.
- **근거**: 검증은 세션이 실제로 돌린 테스트·빌드 결과(시각·명령)로, PR은 검사·검토 상태로 보여 줍니다. 바닥 줄에 언제 읽은 정보인지 적고 "지금 다시 읽기" 단추를 둡니다.
- **단계 칩**: 채팅 머리 오른쪽에 점 여섯 개와 지금 단계 이름이 붙고, 승인 차례면 "승인" 배지가 붙습니다. 누르면 지금 카드와 단계 목록 창이 열립니다.
- **읽기만 합니다**: `git fetch`·`push` 같은 명령은 돌리지 않습니다. 푸시·머지·태그 단추도 없습니다. 승인과 실행은 사람이 직접 합니다.

**여러 저장소를 담은 폴더**(예: `~/Dev`)에서 연 세션은 그 세션이 명령을 돌린 저장소(`cd`·`git -C`·`workdir`, 작업본 `worktrees/<저장소>/<작업본>` 포함)를 자동으로 따라갑니다. 명령에서 찾지 못하면 가장 최근에 Git 활동이 있던 곳을 보여 주고, 왜 그 저장소인지 한 줄로 밝힙니다. 폴더·브랜치 옆 "저장소" 상자에서 하나를 고르면 그 세션에서는 그 저장소만 봅니다(이 기기에 기억). "자동으로 따라가기"를 고르면 다시 자동입니다. 이때 요청 문장 앞에는 "<저장소> 저장소에서"가 붙습니다.

PR 상태는 GitHub CLI(`gh`)로 읽습니다. `gh` 로그인이 만료되면 공유 단계에 "GitHub 로그인 필요"가 뜨고 `gh auth login`을 안내합니다.

## 설치

1. 키트 루트에서 `./install.sh`로 다른 플러그인과 함께 설치합니다. 이것만 넣으려면 DSH Desktop → 플러그인 → 추가에 이 폴더의 **절대 경로**(`<키트 폴더>/plugins/git-stage`)를 넣습니다.
2. 플러그인을 켜고 세션을 열면 `…` 메뉴에 "작업 단계"가 나타납니다.

```bash
"/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" plugin --profile desktop add link:$PWD
```

## 개발

```bash
node scripts/build.mjs
```

```bash
node --test test/*.test.mjs
```

`test/preview.html`은 실제 DSH 없이 탭과 칩을 올려 보는 틀입니다. 주소 뒤에 `?stage=0~6`(단계), `?theme=dark`, `?blocked=gh`(GitHub 로그인 만료), `?repo=0`(저장소 아님), `?within=1`(여러 저장소를 담은 폴더), `?fail=1`(읽기 실패)을 붙입니다. 모듈을 불러오므로 파일로 바로 열지 않고 키트 루트를 정적 서버로 띄워 엽니다.
