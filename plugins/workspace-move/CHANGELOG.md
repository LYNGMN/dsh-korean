# 변경 기록

## 0.1.0 (2026-11-16)

첫 판입니다. DeepSeek Harness 0.2.2-rc.3에서 만들고 시험했습니다.

- 세션 **…** 메뉴에 **작업공간 이동**(폴더 이동 아이콘, **다음에서 열기** 아래)과 **세션 삭제**(휴지통 아이콘·경고색, 맨 아래 **세션 보관** 다음)를 더했습니다. 두 줄은 DSH 공식 메뉴 등록으로 그려서 다른 줄과 아이콘·간격·키보드 이동이 같습니다.
- 세션 삭제: 기록을 휴지통으로 옮기고 작업공간 목록에서 뺍니다. 열린 대화를 지우면 보관 처리로 목록에서 즉시 숨기고, 열린 화면은 앱을 다시 켤 때 사라집니다.
- 결과 화면의 닫기 버튼을 **확인**으로 바꿨습니다.
- 예약 결과와 사이드바 줄 배지(`→ Dev`)로 **어디로 옮기는지 확인**할 수 있고, 다음 시작 때 이동을 마치면 알림으로 알려 줍니다.
- 끌어다 놓으면 닫힌 대화는 바로, 열린 대화는 **대상이 미리 선택된 확인 창**으로 이어집니다.
- 예약 화면에서 **예약 취소**를 할 수 있습니다(Host가 새로 시작된 뒤).
- 열린 대화는 **다시 켜고 그대로 이동**으로 예약합니다. 앱을 완전히 껐다 켜면 같은 세션 id로 자동으로 옮겨집니다(복사본 없음).
- 복사 방식은 넣지 않았습니다. 이동은 같은 세션 id를 유지하고 원본 로그를 지웁니다.
- 이동 로그를 한 번 읽어 새로 씁니다. 16MiB를 넘는 대화는 메모리 때문에 거절합니다(`maxArtifactBytes`로 조절).
- 대화 줄을 다른 작업공간 줄로 **끌어다 놓아도** 옮겨집니다(파란 테두리 표시). 같은 작업공간 안의 순서 바꾸기는 그대로입니다.
- 세션 id·제목·대화 기록을 그대로 두고 헤더 `cwd`와 로그 위치, 작업공간 소유 기록을 함께 옮깁니다.
- 옮기기 전 백업, 진행 저널, 새 로그 검증, 실패 시 자동 되돌리기, 앱 재시작 뒤 복구를 넣었습니다.
- 결과 화면에서 **되돌리기**로 원래 작업공간에 다시 옮길 수 있습니다.
- 열려 있는 대화, 하위 에이전트 대화, 같은 작업공간, 없는 폴더, 큰 로그는 이유를 보여 주고 거절합니다.
- `working-directory/change` 기록이 있는 대화는 옮긴 뒤 대상 경로로 다시 남겨 작업 폴더가 어긋나지 않게 했습니다.
- 이동이 끝난 뒤 정리 단계에서 저널 저장이 실패해도 이동한 대화를 지우지 않습니다. 새 대화가 작업공간 목록에 올라간 뒤에는 되돌리지 않고, 남은 정리는 다음 시작 때 복구가 마칩니다. 되살릴 원본이 없으면 새 로그를 지우지 않고 사람의 복구로 넘깁니다.
