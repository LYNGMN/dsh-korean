# 변경 기록

## 1.2.0

- 입력 안내에 적힌 옵션을 채워 줘요. `/gstack-cso --d`처럼 옵션 앞 글자를 치면 남은 글자(`iff`)를 회색으로 보여 주고, Tab이나 →를 누르면 남은 글자와 공백 하나를 넣어요. `--옵션`은 인자 어디서나, `polish` 같은 하위 명령 낱말은 첫 인자에서만 맞추고, 여러 개가 맞으면 안내 순서의 첫 번째를 보여 줘요. `/` 메뉴가 열려 있거나 한글을 조합하는 중이거나 커서가 글 끝이 아니면 키를 그대로 지나보내요.

## 1.1.0

- `/` 메뉴의 스킬 줄마다 붙던 "사용자 전용 · " 표시를 숨기고, 대신 AI도 스스로 부를 수 있는 스킬에만 "AI 호출 가능 · "을 붙여요. 그런 스킬의 파일 설명은 AI가 읽는 글이라 영어 원문 그대로 두고, 한국어면 메뉴에서만 한국어 요약으로 보여 줘요. 사람용 이름은 사용자 전용이어도 AI가 다른 이름으로 같은 스킬을 부를 수 있으면(`superpowers-systematic-debugging` 등) 그 줄에도 표시를 붙여요. 화면 번들이 메뉴 글자만 고치고, 고르기와 AI가 스킬을 부를 수 있는지는 그대로예요.

## 1.0.0

- 감싸개 설명 방식(`dsh-sync-skills`)을 돕는 플러그인으로 다시 썼어요. `/스킬` 뒤 회색 입력 안내, DSH 언어가 바뀔 때 메뉴 설명 다시 쓰기와 재시작 알림, `/skill-hints` 상태 명령을 내놓아요.
