# 변경 기록

## 1.1.0

- `/` 메뉴의 스킬 줄마다 붙던 "사용자 전용 · " 표시를 숨기고, 대신 AI도 스스로 부를 수 있는 스킬에만 "AI 호출 가능 · "을 붙여요. 그런 스킬은 AI가 읽는 설명이라 영어 원문 그대로인데, 표시로 까닭을 알 수 있어요. 화면 번들이 메뉴 글자만 고치고, 고르기와 AI가 스킬을 부를 수 있는지는 그대로예요.

## 1.0.0

- 감싸개 설명 방식(`dsh-sync-skills`)을 돕는 플러그인으로 다시 썼어요. `/스킬` 뒤 회색 입력 안내, DSH 언어가 바뀔 때 메뉴 설명 다시 쓰기와 재시작 알림, `/skill-hints` 상태 명령을 내놓아요.
