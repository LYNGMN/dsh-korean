# skill-hints

DeepSeek Harness(DSH)의 `/` 메뉴에서 사용자 전용 스킬 옆 설명을 DSH 언어에 맞춰 보여 줍니다. 한국어면 한국어 요약 뒤에 세부 명령 안내(`argument-hint`)를 붙입니다.

## 왜 필요한가

DSH는 `/` 메뉴에 "명령"과 "스킬"을 따로 보여 주고, 스킬 설명은 원문(대개 영어) 그대로 씁니다. 스킬 머리말의 `argument-hint`도 읽지 않습니다.
예전 판은 스킬마다 같은 이름의 명령을 등록해 설명과 입력 안내를 붙였는데, DSH가 같은 이름을 합치지 않아 메뉴에 명령 줄과 스킬 줄이 두 번 보였습니다.
그래서 지금은 명령을 만들지 않고, 스킬 제공자(`ctx.skills.registerProvider`)로 같은 스킬을 사용자 폴더보다 앞선 순위(350)로 다시 내놓아 스킬 줄 하나의 설명만 바꿉니다.

## 어떤 스킬이 대상인가

- `~/.dsh/skills`(순위 400)와 `~/.agents/skills`(500)에서 DSH와 같은 규칙으로 찾습니다. 같은 이름이면 앞쪽이 이깁니다. 프로젝트 폴더와 사용자 지정 폴더(300 이하)의 스킬은 그대로 이깁니다.
- 이긴 쪽이 사용자 전용(`disable-model-invocation: true`)인 스킬만 대상입니다. 모델도 부르는 스킬은 설명이 모델의 판단 글이기도 해서 건드리지 않습니다. `user-invocable: false`도 뺍니다.
- 설명: DSH 언어가 한국어면 `~/.agents/skill-hints.json`의 `summary`(없으면 영어)와 입력 안내, 그 밖의 언어면 실제 `SKILL.md` `description`을 씁니다. 160자를 넘으면 단어 경계에서 줄입니다. 입력 안내는 한국어로 쓰여 있어 한국어에서만 붙입니다.
- 입력 안내는 실제 `SKILL.md`의 `argument-hint`, 없으면 오버레이의 `hint`를 씁니다. 감싸개(`~/.dsh/skills/<이름>.md`)는 그 안에 적힌 실제 `SKILL.md`에서 읽습니다.
- 본문·기준 폴더·경로는 DSH 파일 제공자와 같게 두고, 스킬을 부를 때 파일에서 다시 읽습니다. 모델이 받는 설명은 원문 그대로입니다.
- 머리말의 `metadata` 칸은 넘기지 않습니다(YAML 라이브러리 없이 읽기 때문).

DSH 언어를 바꾸면 목록을 새로 받게 합니다. 스킬 파일이 바뀌면 DSH 파일 제공자가 같은 목록 캐시를 비우므로 요약도 다시 읽습니다. 화면에 남은 목록은 새 대화에서 바뀔 수 있습니다.

## "사용자 전용" 표시 숨기기

DSH는 `/` 메뉴에서 사용자 전용 스킬 설명 앞에 "사용자 전용 · "을 붙입니다. 사용자 스킬은 대부분 사용자 전용이라 거의 모든 줄에 같은 말이 반복되므로, 화면 쪽 번들(`client.js`)이 메뉴의 스킬 줄에서 이 앞부분만 지웁니다.

- 입력창 카드 안 공식 자리(`conversation.input.overlay`)에 보이지 않게 들어가, 그 카드 안 `/` 메뉴의 스킬 줄(`dsh-slash-option-skill-*`) 글자만 고칩니다. 명령 줄과 메뉴 밖 글은 건드리지 않습니다.
- DSH가 지원하는 모든 언어의 표시 문구(한국어 언어팩 번역 포함)를 알아봅니다.
- 글자만 바꾸므로 고르기·Tab·엔터 키, AI가 스킬을 부를 수 있는지(`disable-model-invocation`)는 그대로입니다.
- DSH가 메뉴 구조나 문구를 바꾸면 원래 표시가 다시 보일 뿐 메뉴는 그대로 동작합니다.

## 설치

한국어 DSH 키트의 다른 플러그인과 함께 저장소 루트에서 `./install.sh`로 설치합니다.
이 플러그인만 넣으려면 DSH 플러그인 화면 → **플러그인 추가**에 이 폴더의 절대 경로(`<키트 폴더>/plugins/skill-hints`)를 넣습니다.

## 시험

```bash
~/.dsh/dsh-runtimes/dsh-primary-runtime/dependencies/node/bin/node --test test/plugin.test.js test/client.test.mjs
```

## 되돌리기

DSH 플러그인 화면에서 이 플러그인을 끄거나 제거합니다. 끄면 스킬은 원래 파일 제공자가 내놓는 원문 설명으로 돌아갑니다. 키트 전체를 빼려면 저장소 루트에서 `./install.sh --remove`를 실행합니다.
