# skill-hints

DeepSeek Harness(DSH)의 스킬 메뉴 설명 방식(감싸개 파일)을 돕는 플러그인입니다. 세 가지를 합니다.

1. **회색 입력 안내**: 입력창에 `/스킬이름`만 치면 그 뒤에 흐린 글씨로 무엇을 더 적을 수 있는지(`argument-hint`) 보여 줍니다. 글을 이어 치면 사라집니다.
2. **언어 맞추기와 재시작 알림**: DSH를 켤 때와 DSH 언어를 바꿀 때 `~/.agents/bin/dsh-sync-skills --apply`를 그 언어로 돌려 메뉴 설명을 다시 씁니다. 바뀐 것이 있으면 입력창 아래에 "DSH를 완전히 종료했다 다시 켜세요" 알림을 띄웁니다.
3. **`/skill-hints` 명령**: 언어, 스킬 수, 한국어 요약이 빠진 스킬, 메뉴 설명이 언어와 맞는지 보여 줍니다. `/skill-hints sync`는 바로 맞춥니다.

## 지금 방식과 무엇이 다른가

| | 감싸개 파일(`dsh-sync-skills`) | 이 플러그인 |
|---|---|---|
| 맡는 것 | `/` 메뉴의 스킬 한 줄 설명 | 입력창의 회색 안내, 언어 맞추기 시점, 상태 보기 |
| 어디서 | `~/.dsh/skills/*.md` 파일 | DSH 안(호스트 + 화면) |
| 언제 바뀌나 | 스크립트를 돌리고 DSH를 다시 켤 때 | 바로(입력할 때, 언어를 바꿀 때) |

메뉴 설명을 플러그인이 직접 바꾸지 않는 까닭: DSH는 작업 모드(프리셋)마다 스킬 파일을 다시 읽어, 플러그인이 내놓은 같은 이름 스킬을 늘 덮습니다. 그래서 설명은 파일로 바꾸고, 이 플러그인은 파일을 바꾸는 스크립트를 알맞은 때 부르기만 합니다.

## 어떤 스킬이 대상인가

- `~/.dsh/skills`와 `~/.agents/skills`에서 DSH와 같은 규칙으로 찾습니다. 같은 이름이면 앞쪽이 이깁니다. `user-invocable: false`는 뺍니다.
- 입력 안내는 실제 `SKILL.md`의 `argument-hint`, 없으면 `~/.agents/skill-hints.json`의 `hint`를 씁니다. 감싸개(`~/.dsh/skills/<이름>.md`)는 그 안에 적힌 실제 `SKILL.md`에서 읽습니다. 안내 글이 한국어라 DSH 언어가 한국어일 때만 보입니다.
- DSH 명령이 자기 안내를 쓰는 중이면 건드리지 않습니다. 줄이 둘 이상이거나 글을 더 치면 안내를 지웁니다.
- 맞추기는 `dsh-sync-skills --apply`를 그대로 돌리므로, 설명과 함께 새로 깐 스킬의 `~/.dsh/skills` 연결도 맞춰집니다.
- `dsh-sync-skills`가 없는 맥에서는 언어 맞추기를 하지 않고, `/skill-hints`가 그렇다고 알려 줍니다.

## 설치

한국어 DSH 키트의 다른 플러그인과 함께 저장소 루트에서 `./install.sh`로 설치합니다.
이 플러그인만 넣으려면 DSH 플러그인 화면 → **플러그인 추가**에 이 폴더의 절대 경로(`<키트 폴더>/plugins/skill-hints`)를 넣습니다.

## 시험

```bash
node --test test/*.test.js
```

화면 시험(`test/client.test.js`)은 npx 캐시에 Playwright가 있을 때만 돌고, 없으면 건너뜁니다.

## 되돌리기

DSH 플러그인 화면에서 이 플러그인을 끄거나 제거합니다. 끄면 회색 안내와 알림이 사라지고, 메뉴 설명은 마지막으로 쓴 감싸개 파일 그대로 남습니다. 키트 전체를 빼려면 저장소 루트에서 `./install.sh --remove`를 실행합니다.
