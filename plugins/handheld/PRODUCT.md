# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

한 사람(이 저장소의 주인)이 자기 컴퓨터에서 돌아가는 DeepSeek Harness(DSH)를 휴대폰으로 다룹니다. 주로 침대·소파처럼 자리에 앉아 대화를 길게 읽고 글을 많이 보내며, 중간에 오는 승인 요청과 질문에 답합니다. (2026-11-15 사용자 답)

## Product Purpose

DSH Desktop 앞에 앉아 있지 않아도 세션을 이어 보고, 글을 보내고, 승인·질문에 답하고, 바뀐 파일을 확인하게 합니다. 휴대폰에서 놓치는 일 없이 작업이 계속 흘러가면 성공입니다.

## Positioning

DSH 화면을 비추거나 고쳐 쓰지 않고, DSH가 공식으로 여는 API 손님 경로만 쓰는 개인용 게이트웨이와 설치형 앱(PWA)입니다. 승인은 사람이 직접 누를 때만 나갑니다.

## Operating Context

- 휴대폰 홈 화면에 설치한 앱으로 엽니다. 외부 접속은 Cloudflare Tunnel과 Access를 거칩니다.
- 화면은 세션 목록, 대화, 승인·질문 시트, 변경 파일 비교, 설정입니다.
- 승인 요청·질문·작업 끝은 Web Push로 알립니다.

## Capabilities and Constraints

- 화면 글자는 한국어 기본이고 설정에서 영어·일본어·중국어 간체·번체로 바꿀 수 있습니다. 한국어에는 `word-break: keep-all`, 입력창 16px 이상, 터치 대상 44px 이상입니다.
- PWA 의존성은 Preact와 esbuild, 그리고 앱에 묶어 넣는 글꼴 두 개(Pretendard, D2Coding)입니다. 아이콘은 Lucide 그림을 옮겨 쓰고 패키지는 들이지 않습니다.
- 자동 승인 코드를 넣지 않습니다.
- 화면을 다듬어도 한 화면에 보이는 정보를 줄이지 않고, 누른 뒤 반응이 효과 때문에 느려지지 않아야 합니다. (2026-11-15 사용자 답)

## Brand Commitments

- 이름: 앱 "DSH 휴대폰", 플러그인 카드 "휴대폰 작업 공간".
- 색: DeepSeek 브랜드 파랑 `#4D6BFE`를 씁니다(설치된 DSH 앱이 쓰는 값). 플러그인 카드 아이콘은 DSH 파란 그라데이션(`#3D94EE`→`#3F77D8`)입니다. (2026-11-15 사용자 요청: "딥시크 브랜드컬러를 활용")
- 피할 모습: 화려한 장식(번쩍이는 그라데이션, 유리 효과, 눈에 띄는 움직임), 브랜드 색이 안 보이는 밋밋한 회색 화면. (2026-11-15 사용자 답)
- 글꼴: 글은 Pretendard, 코드는 네이버 D2Coding을 앱에 넣어 어느 환경에서나 같게 보입니다. (2026-11-15 사용자 요청)
- 색은 눈이 피로하지 않게 넓은 면을 옅게 하고, 강조 색과 말풍선 농도를 사용자가 고릅니다. 브랜드 색만 쓰는 것은 아닙니다. (2026-11-15 사용자 요청)
- 밝음·어두움을 사용자가 직접 바꿀 수 있어야 합니다. 세션 목록 상단 아이콘으로 한 번에 바꾸고, 설정에서 자동·밝음·어두움 중에 고릅니다. (2026-11-15 사용자 답)

## Evidence on Hand

- 개발용 가짜 DSH 시연 대화(`scripts/dev.mjs`): 로그인 화면 수정 세션, 승인 요청 흐름.
- 실제 DSH에서 녹화해 거른 프레임(`test/fixtures/0.2.2-rc.3/`).
- 사용 후기·사용자 수 같은 자료는 없습니다. 만들어 넣지 않습니다.

## Product Principles

1. 읽기가 먼저입니다. 긴 대화와 코드가 휴대폰 폭에서 편하게 읽혀야 합니다.
2. 승인은 무엇을 허용하는지 보고 사람이 직접 누릅니다.
3. 상태(실행 중, 답 필요, 연결 끊김)는 색만이 아니라 글자와 모양으로도 보입니다.
4. 꾸밈보다 반응 속도가 먼저입니다.

## Accessibility & Inclusion

WCAG 2.2 AA를 목표로 검토합니다. 밝음·어두움 모두 글자 4.5:1, 조작 요소 3:1, 동작 줄이기 설정을 따릅니다.
