# 변경 기록

## 1.2.0 (2026-11-18)

- 작업 단계: 열린 세션이 Git 저장소 폴더에서 일하면 대화 화면 위에 "저장 단계 · 2/6" 같은 띠가 생깁니다. 누르면 작업실·고치고 저장·검증·공유·합치기·배포 여섯 단계가 끝남·지금·남음으로 보이고, 단계마다 쉬운 뜻·지금 상태·다음 할 일과 "승인 필요" 표시가 있습니다. 에이전트의 진행 중 할 일도 "지금 하는 일"로 같이 보입니다. Git은 읽기만 하고 푸시·머지 단추는 없습니다. 작업 중이면 8초, 아니면 30초마다 다시 읽습니다. 여러 저장소를 담은 폴더(예: `~/Dev`)의 세션은 그 세션이 명령을 돌린 저장소를(못 찾으면 가장 최근에 Git 활동이 있던 저장소를) 따라가고 이유를 한 줄로 밝힙니다. 시트 위 상자에서 저장소를 고정할 수 있습니다. 공유·합치기 단계에는 승인 전에 올라갈 저장 기록 제목·바뀐 파일 수와 올라가지 않는 저장 안 된 변경이 보입니다. 검증은 세션이 실제로 돌린 테스트·빌드 결과("14:02 npm test 통과")로 보고, 그 뒤에 파일을 고쳤으면 다시 돌리라고 합니다. 열린 PR의 검사·검토 상태가 한 줄로 보이고, 검사가 실패하면 합치기 단계에 "검사 실패"가 붙습니다. 배포 단계는 그 저장소의 배포 방식(Wrangler·`npm run deploy`·태그)에 맞춰 말합니다. 에이전트가 일하는 중이면 작업실·저장·검증 단계의 다음 할 일이 "기다렸다가, 끝나면 …"으로 바뀝니다. 지금 단계에는 다음 몇 걸음을 묶은 "이렇게 요청해 보세요" 문장이 있고, "입력창에 넣기"를 누르면 시트가 닫히며 쓰던 글 뒤에 그 문장이 들어갑니다. 보내기는 직접 누릅니다.
- 작업 끝 알림: 작업이 끝났을 때 작업 단계가 승인을 기다리면 알림 본문에 "답변이 끝났습니다 · 공유 승인 필요"처럼 그 단계를 붙입니다. 작업이 끝날 때 Git을 한 번만 읽고(최대 4초), 못 읽으면 단계 없이 보냅니다.

## 1.1.0 (2026-11-18)

- 언어: 설정 → 화면 → 언어에서 한국어(기본)·English·日本語·简体中文·繁體中文 중에 고릅니다. 화면 글자와 푸시 알림이 그 언어로 나오고, 대화 내용은 바뀌지 않습니다. 일본어·중국어에서는 변환을 확정하는 엔터 키가 글을 보내지 않습니다.
- 계획 검토: DSH가 계획 모드를 끝내려고 계획을 내면, 영어 질문("Approve"·"Keep planning") 대신 Desktop과 같은 "계획 검토" 화면으로 보입니다. 계획 전체를 읽고 "승인"이나 "수정 요청"(고칠 점을 적어 보낼 수 있음)을 누릅니다. 목록과 알림에도 "계획 검토 · 계획 제목"으로 나옵니다.
- 다듬은 모습: 모서리를 세 단계(12·16·24px)로 통일하고 면을 나누는 선을 옅게 했습니다. 고르기 단추의 파란 칸이 고른 쪽으로 미끄러지고, 도구 줄이 부드럽게 펼쳐집니다. 계획 검토에는 결재란(올림·승인)이 생겨 승인하면 파란 도장이 찍힌 뒤 닫힙니다. 설정 → 화면 → 움직임에서 "줄이기"를 고르면 움직임 없이 바로 바뀝니다.
- 아이콘: 모든 아이콘을 Lucide 원본 그림으로 바꿨습니다(패키지는 넣지 않고 그림만 옮김). 계획 검토는 목록 달린 클립보드, 도구는 스패너, 설정은 톱니바퀴입니다. 묶음 안에서 크기나 중심이 어긋나 보이는 아이콘(달, 보내기 화살표, 더하기, 멈춤, 체크, 경고 등)은 재서 보정했습니다. 언어 선택의 화살표도 같은 아이콘입니다.
- 초점 표시: 테두리가 있는 입력창·단추는 초점을 받으면 테두리 자리에 한 줄로만 표시합니다(테두리 밖에 링이 하나 더 생기던 이중선을 없앰). 나란한 아이콘 단추 사이는 8px입니다.
- 명령어: 입력창 왼쪽의 명령어 단추를 누르면 DSH가 그 세션에서 받는 명령어(`/plan` 등) 목록이 이름·설명과 함께 뜹니다. 입력창에 `/`를 치면 이름이 맞는 명령어가 바로 위에 제안됩니다. 고른 명령어는 입력창에 들어가고 보내기를 눌러야 실행됩니다. DSH가 모르는 `/글`(예: `/etc/hosts …`)은 그대로 메시지로 보냅니다. 하위 에이전트 대화에서는 쓸 수 없습니다.
- 작업 중에 보내는 방식(대기열·끼어들기)은 입력창 위에 나란한 두 칸으로 보이고, 칸마다 이름 아래에 하는 일("끝난 뒤에 보내기"·"지금 바로 반영")이 적혀 있습니다.

## 1.0.0 (2026-11-15)

첫 공개판입니다.

- 휴대폰 앱(PWA): 세션 목록, 대화(이전 기록·실시간 답변·읽던 위치 복원), 승인·질문 시트, 바뀐 파일 비교, 설정(알림 켜기·시험 알림·작업 끝 알림). 세션마다 쓰던 글을 저장하고, 브라우저가 지원하면 음성 입력 버튼이 보입니다.
- 하위 에이전트 대화 보기: 세션이 하위 에이전트에게 일을 맡기면 대화 화면 위에 "하위 에이전트 N개" 줄이 생깁니다. 누르면 목록(이름·상태)이 나오고, 하나를 고르면 그 대화를 실시간으로 볼 수 있습니다. 보기 전용이라 글 보내기와 중단은 부모 세션에서 합니다.
- 디자인: 표준 메신저 모양입니다. 강조색은 DeepSeek 파랑(`#4D6BFE`)이고, 초록·호박·빨강은 상태에만 씁니다.
- 화면 옵션(설정 → 화면, 이 기기에 저장): 테마(자동·밝게·어둡게, 세션 목록 상단의 해·달 아이콘으로 한 번에 전환), 강조 색(딥시크·남색·회색), 내 글 말풍선(은은하게·선명하게), 글꼴, 대화 글자 크기, 대화 간격, 생각 과정 보이기.
- 글꼴: 글은 Pretendard, 코드는 D2Coding을 앱에 넣어 어느 기기에서나 같게 보입니다(둘 다 OFL-1.1). 화면에 나온 글자에 필요한 조각만 받고, 받은 조각은 오프라인에서도 씁니다. 설정에서 기기 글꼴로 바꿀 수 있습니다.
- 입력창 엔터 키: 설정에서 바로 보내기(기본)·줄바꿈 중에 고릅니다. Shift+엔터는 늘 줄바꿈이고, 한글을 쓰는 중에도 엔터 키 한 번이면 글자를 확정하고 보냅니다. 작업 중에는 Cmd/Ctrl+엔터가 고른 방식(대기열·끼어들기)의 반대로 보냅니다.
- 승인 시트에 "허용하면 실행할 내용"(도구 호출 제목·명령·바뀔 파일 미리 보기)을 보여 줍니다.
- 대화에서 화면 절반 넘게 올라가 있으면 "맨 아래로" 단추가 보입니다. 코드 블록에는 복사 단추가 있습니다. 알림 글은 입력창을 가리지 않게 화면 위쪽에 뜹니다.
- 접근성(WCAG 2.2 AA 검토): 화면을 옮기면 탭 제목이 바뀌고 초점이 제목으로 갑니다. 고르기 단추 묶음은 화살표 키로 움직입니다. 작업 시작·끝과 새 승인 요청을 화면 낭독기에 알립니다.
- 알림: 승인 요청·질문·작업 끝을 Web Push로 보냅니다. 승인은 사람이 직접 누를 때만 나갑니다.
- 게이트웨이: DSH 플러그인이 `127.0.0.1:3090`에 띄웁니다. 마지막으로 받은 위치부터 이어 보내고, 모자란 구간은 DSH 기록에서 채웁니다. 답변 글은 0.1초 단위로 바뀐 부분만 보냅니다. 글꼴 파일(`.woff2`)은 `font/woff2`로 내보냅니다. `GET /sessions/:id/subagents`로 하위 에이전트 목록을 주고, 하위 에이전트 대화는 DSH의 하위 에이전트 주소로 따라갑니다. 바깥에서 실행되는 하위 에이전트는 열 대화가 없어 목록에서 뺍니다.
- 보안: Cloudflare Access 로그인 표(JWT)를 직접 검사하고, 설정이 비어 있으면 바깥 요청을 모두 거부합니다. 쓰기 요청과 실시간 연결은 출처(Origin)를 확인합니다. 토큰과 알림 서명 키는 본인만 읽을 수 있게(0600) 저장합니다.
- 바깥 접속: 설정이 있으면 `cloudflared` 터널을 띄우고 지켜 줍니다. 대시보드에서 만든 터널과 명령줄로 만든 터널을 모두 씁니다.
- 설정 도우미 `scripts/configure.mjs`: 질문에 답하거나 인자(`--origin`, `--team`, `--aud`, `--emails`)로 설정합니다. 안내서는 `docs/setup-cloudflare.md`(한국어)와 `docs/setup-cloudflare.en.md`(영어)입니다.
- 휴대폰 화면 빌드물(`web/dist/`)이 들어 있어 따로 빌드하지 않아도 됩니다.
