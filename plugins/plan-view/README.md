# dsh-plan-view

DeepSeek Harness(DSH) Desktop 대화 머리의 보기 탭(`채팅 · 실행 흐름 · …`)에 **계획** 보기를 더하는 플러그인입니다. DeepSeek 공식 플러그인이 아닙니다. 대화가 길어져도 계획과 진행을 한 화면에 띄워 둘 수 있습니다.

- **할 일**: 에이전트의 할 일을 실시간으로 체크합니다. 진행 막대와 진행 중 항목의 경과 시간이 보이고, 항목을 누르면 시작·완료 시각과 "실행 흐름에서 보기"가 나옵니다. 새 메시지를 보내도 목록이 남고, 이전 턴 목록은 "지난 할 일"에 쌓입니다.
- **진행 칩**: 채팅 머리 오른쪽에 "2/4" 칩이 붙습니다. 누르면 할 일 창이 열립니다.
- **제출된 계획**: `/plan`(계획 모드)에서 제출된 계획 문서를 읽기 좋게 그려 최신순으로 보여 줍니다. 할 일과 문구가 비슷한 단계는 자동으로 체크됩니다.

DSH가 플러그인에게 열어 둔 "대화 보기" 자리(`conversation.view`)에 들어가므로, `…`(다른 대화 보기 방식) 메뉴에서 탭으로 고정하거나 뺄 수 있습니다.

## 설치

1. 키트 루트에서 `./install.sh`로 다른 플러그인과 함께 설치합니다. 이것만 넣으려면 DSH Desktop → 플러그인 → 추가에 이 폴더의 **절대 경로**(`<키트 폴더>/plugins/plan-view`)를 넣습니다. `~/`로 시작하는 경로는 패키지 이름으로 읽혀 설치되지 않습니다.
2. 플러그인을 켜고 세션을 열면 `…` 메뉴에 "계획"이 나타납니다.

터미널에서는 DSH에 들어 있는 명령으로도 설치할 수 있습니다. 설치와 함께 켜집니다.

```bash
"/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" plugin --profile desktop add link:$PWD
```

## 개발

```bash
node scripts/build.mjs
```

```bash
node --test test/*.test.mjs
```

`test/preview.html`은 실제 DSH 없이 탭과 칩을 올려 보는 틀입니다. 브라우저로 파일을 바로 엽니다. 주소 뒤에 `?theme=dark`(어두운 테마), `?step=0~3`(진행 단계), `?carried=1`(새 턴), `?empty=1`(빈 화면)을 붙일 수 있고, "실시간 재생" 단추로 체크가 넘어가는 모습을 봅니다.
