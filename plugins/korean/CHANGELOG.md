# 변경 기록

## 1.0.0 (2026-11-15)

첫 공개판입니다. DeepSeek Harness 0.2.2-rc.2의 영어 원문을 기준으로 번역했습니다.

- 화면 사전 76개 네임스페이스를 한국어로 번역했습니다. 설정 → 일반 → 언어에 한국어가 생깁니다.
- 내장 플러그인 카드(실험적 플러그인 포함)의 이름·설명 167개를 한국어로 보여 줍니다.
- 글꼴 고르기: 설정 → 일반에서 본문·코드·터미널 글꼴을 설치된 글꼴 목록에서 고릅니다. "기본값" 항목에는 실제로 쓰이는 글꼴 이름이 보입니다.
- 추천 글꼴: 본문 Pretendard, 코드 D2Coding, 터미널 IBM Plex Mono. 처음 켤 때 DSH 기본 글꼴을 쓰고 있고 추천 글꼴이 설치돼 있으면 한 번만 바꿔 줍니다. 이미 고른 글꼴은 그대로 둡니다.
- 메뉴 막대·업데이트 창 같은 앱 본체 문구 189개의 번역(`desktop/ko.json`)이 들어 있습니다. 언어팩으로는 적용할 수 없는 부분이라 DSH 본체에 제안하는 용도입니다.
- 설치된 앱에서 영어 원문을 뽑는 추출기, 번역 검사기(`npm run check`), 번들 빌드 스크립트.
