# 번역하는 방법

`source/<앱 버전>/en/<네임스페이스>.json`의 영어 문구를 한국어로 옮겨 `ko/<네임스페이스>.json`에 씁니다.

플러그인 카드의 이름·설명은 `source/<앱 버전>/packages-en.json`을 보고 `packages/ko.json`에 같은 키로 씁니다. 제목은 명사형, 설명은 해요체입니다. 화면에서 영어 원문으로 번역을 찾기 때문에, 원문이 같은 두 키는 번역도 같아야 합니다.

## 먼저 읽을 것

- [STYLE.md](../STYLE.md): 문체 기준. 문장은 해요체, 버튼·메뉴·탭·제목은 명사형, 줄표(—, –) 금지, 번역투 금지.
- [glossary.json](../glossary.json): `terms`의 번역어를 그대로 씁니다. `enforce: false`인 용어는 그 뜻으로 쓰였을 때만 따릅니다. `keep`의 말은 영어로 둡니다. `verbatimKeys`의 키는 원문 그대로 둡니다.
- 이미 번역된 `ko/common.json`, `ko/conversation.json`: 같은 영어 문구(Cancel, Retry, Loading… 등)는 여기 번역과 똑같이 씁니다.
- `source/<앱 버전>/index.json`의 `sameInEveryLanguage`: 앱이 모든 언어에서 영어 그대로 둔 키입니다. 원문 그대로 둡니다.

## 규칙

- 원문의 모든 키를 원문과 같은 순서로 넣습니다. 키를 빼거나 더하지 않습니다.
- `{name}` 같은 플레이스홀더는 이름과 개수를 그대로 두고, 위치만 한국어 어순에 맞춥니다. 플레이스홀더 뒤에 "을(를)" 같은 병기 조사를 쓰지 않고 문장을 바꿔 피합니다.
- `.one`/`.other` 복수형 키는 둘 다 같은 한국어 문장으로 씁니다.
- 원문의 앞뒤 공백, 줄바꿈, `…`, 마크다운 문법을 유지합니다. 원문이 빈 문자열이면 빈 문자열로 둡니다.
- 도구 이름(Bash, Grep 등), 슬래시 명령, API 필드, 파일 경로, 예시 URL, 키보드 키 이름은 원문 그대로 둡니다.
- 원문에 없는 내용을 더하지 않고, 조건·범위·가능성 표현을 빼지 않습니다.
- 같은 영어 문구는 같은 한국어로 맞춥니다.
- 짧은 버튼·라벨은 한 줄에 들어가게 짧게 씁니다.
- 상태 표시는 "실행 중", "완료됨", "실패", "중지됨", "취소됨", "일시 중지됨", "대기 중"으로 씁니다.
- 시간 단위 약어(s, min, h, d, mo, y)는 초, 분, 시간, 일, 개월, 년으로 씁니다.
- 영어 원문만 보고 옮깁니다. 다른 언어팩이나 인터넷의 기존 한국어 번역을 가져오지 않습니다.
- 문맥이 애매하면 같은 파일의 이웃 키와 키 이름으로 판단합니다.

## 검사

```bash
node scripts/check.mjs --allow-incomplete
```

맡은 네임스페이스의 문제를 모두 고칩니다. 용어 규칙이 뜻이 다른 낱말에 잘못 걸리면 억지로 용어를 넣지 말고 `glossary.json`의 `exceptions`에 `"네임스페이스": ["키"]` 형식으로 올립니다. 도구 이름처럼 영어로 둬야 하는 말이 "한글이 없습니다"에 걸리면 `keep`에 올립니다.

같은 원문을 다르게 옮긴 곳은 아래 명령으로 봅니다.

```bash
node scripts/check.mjs --allow-incomplete --consistency
```
