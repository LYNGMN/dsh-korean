# dsh-korean

DeepSeek Harness(DSH) 화면을 한국어로 보여 주는 언어팩입니다. DeepSeek 공식 언어팩이 아닙니다.

[English](README.en.md)

- 앱 파일을 고치지 않습니다. DSH가 플러그인에 제공하는 언어팩 기능으로 한국어를 추가합니다.
- 앱을 업데이트해도 그대로 남습니다. 새 버전에서 생긴 문구만 번역이 추가될 때까지 영어로 보입니다.
- 끄거나 제거하면 원래 화면으로 돌아갑니다.
- 설정 → 일반에 글꼴 고르기를 넣습니다. 이 기기에 설치된 한글·코딩 글꼴을 목록에서 고를 수 있습니다.


## 지원 버전

| DSH 버전 | 상태 |
|---|---|
| 0.2.2-rc.2 (macOS) | 이 버전의 화면 사전을 기준으로 번역했습니다 |

다른 버전에서도 설치는 되지만, 그 버전에만 있는 문구는 영어로 보입니다.

## 설치

한국어 DSH 키트에 들어 있습니다. 키트 저장소를 내려받아 루트에서 `./install.sh`를 실행하면 다른 플러그인과 함께 설치됩니다.

이것만 넣으려면:

1. DSH에서 **플러그인 → 플러그인 추가**를 엽니다.
2. 키트 폴더 안 `plugins/korean`의 **절대 경로**를 넣고 설치합니다. `~/`로 시작하는 경로는 패키지 이름으로 읽혀 설치되지 않습니다.
3. **설정 → 일반 → 언어**에서 **한국어**를 고릅니다.

## 글꼴 고르기

**설정 → 일반**의 글꼴 크기 줄 아래에 본문·코드·터미널 글꼴을 고르는 줄이 생깁니다.

- 후보 글꼴 가운데 이 기기에 설치된 것만 목록에 보입니다. 글꼴을 새로 설치하면 설정을 다시 열 때 나타납니다.
- 영문 코딩 글꼴을 고르면 한글은 D2Coding이나 나눔고딕코딩으로 나오도록 뒤에 붙여 저장합니다.
- 추천 글꼴은 본문 Pretendard, 코드 D2Coding, 터미널 IBM Plex Mono이고 목록에 "(추천)"으로 보입니다. 언어팩을 처음 켤 때 아직 DSH 기본 글꼴을 쓰는 칸은, 추천 글꼴이 설치돼 있으면 그 글꼴로 한 번 바꿉니다. 설치돼 있지 않으면 기본 글꼴을 그대로 쓰다가, 설치한 뒤 DSH를 다시 켤 때 바꿉니다.
- "기본값"을 고르면 DSH 기본 글꼴로 돌아갑니다. 고른 값은 DSH 설정에 저장되므로 언어팩을 꺼도 남습니다.
- 글꼴 파일은 들어 있지 않습니다. 쓰고 싶은 글꼴은 직접 설치합니다(예: `brew install --cask font-pretendard font-d2coding font-ibm-plex-mono`).
- 후보를 더하려면 `src/font-picker.js`의 `CANDIDATES`·`CODE_FONTS`에 한 줄을 넣고 다시 빌드합니다.

## 끄기와 제거

DSH의 플러그인 화면에서 "한국어 언어팩"을 끄거나 제거합니다. 한국어를 고른 상태에서 언어팩을 없애면 DSH가 브라우저·운영체제 언어에 맞는 언어로 돌아갑니다.

## 한국어로 바뀌지 않는 곳

언어팩은 DSH의 화면 사전과 내장 플러그인 카드의 이름·설명만 바꿀 수 있어서 아래는 영어로 남습니다.

- macOS 메뉴 막대, 트레이 메뉴, 업데이트 창, 처음 실행 환영 창(앱 본체에 문구가 들어 있어 플러그인이 바꿀 수 없습니다. 번역은 `desktop/ko.json`에 준비해 두었습니다)
- 서버가 보내는 오류 원문과 도구 설명
- 다른 사람이 만든 플러그인의 카드와 화면(그 플러그인이 `locale/ko.json`과 한국어 사전을 넣어야 합니다)
- 설정의 플러그인 목록에서 `ui-chat`처럼 식별자로 보이는 내부 모듈 이름
- 터미널의 `dsh` 명령 출력

자세한 목록은 [docs/untranslated.md](docs/untranslated.md)에 있습니다.

## 번역 고치기

번역이 어색하거나 틀린 곳을 발견하면 `ko/<네임스페이스>.json`에서 해당 문구를 고칩니다. 플러그인 카드의 이름·설명은 `packages/ko.json`에 있습니다. 문체는 [STYLE.md](STYLE.md), 용어는 [glossary.json](glossary.json)을 따릅니다.

```bash
node scripts/check.mjs
```

```bash
node scripts/build.mjs
```

```bash
node --test test/*.test.mjs
```

검사기는 영어 원문과 대조해 빠진 키, 원문에 없는 키, 플레이스홀더 불일치, 빈 값, 보이지 않는 문자, 번역되지 않은 값, 용어집과 다른 번역어, 줄표를 찾습니다. 검사를 통과해야 `lib/client.js`가 만들어집니다.

## 새 DSH 버전에 맞추기

```bash
node scripts/extract.mjs
```

설치된 앱에서 영어 원문을 다시 뽑아 `source/<버전>/`에 저장합니다. 앱에는 아무것도 쓰지 않습니다. 그다음 `node scripts/check.mjs`가 새로 생긴 키와 없어진 키를 알려 줍니다.
