# 변경 기록

## 1.1.0 (2026-11-25)

- 자동완성 뒤 글 지키기: 글을 써 두고 커서를 앞으로 옮겨 `/스킬일부`를 친 뒤 Tab(또는 엔터 키)으로 고르면, DSH 0.2.2-rc.5에서 `/스킬이름 `만 남고 커서 뒤 글이 사라지는 일이 있었어요. 고르기 직전 커서 뒤 글을 기억했다가, 고른 뒤 0·80·300ms에 사라진 것이 보이면 DSH 붙여넣기 길로 다시 넣고 커서를 고른 항목 바로 뒤로 돌려놓아요. 정상으로 골라졌으면 아무것도 하지 않아요.
- 되살렸을 때 개발자 도구 콘솔에 `[dsh-enter-keys] Tab으로 고른 뒤 사라진 글 N자를 되살렸어요(Nms)`가 남아요. 글 내용은 남기지 않아요.
- 커서 뒤에 칩·인용이 섞여 있으면 글로 되살릴 수 없어 손대지 않아요. 마우스로 고를 때는 아직 지키지 않아요.

## 1.0.0 (2026-11-15)

첫 공개판입니다.

- 설정 → 일반에 "엔터 키를 누르면: 바로 보내기 / 줄바꿈" 줄이 있습니다. 기본은 바로 보내기이고, DSH "작업 중 보내기 방식" 바로 다음에 놓입니다. 설정은 Desktop을 다시 켜도 남습니다.
- 한글 마지막 글자를 조합하는 중에 누른 엔터 키도 한 번에 처리합니다. 조합 중 Cmd/Ctrl+엔터도 한 번에 됩니다.
- 줄바꿈을 고르면 엔터 키는 줄을 바꾸고, Cmd/Ctrl+엔터로 보냅니다. Shift+엔터는 두 설정 모두 줄바꿈입니다.
- `/`·`@` 자동완성 메뉴가 열려 있으면 엔터 키는 항목을 고르고, 한글이 아닌 조합(일본어·중국어 후보 고르기)은 DSH 원래 동작을 그대로 둡니다.
- 플러그인 카드: 엔터 키 아이콘(Lucide `corner-down-left`, DSH 파란색)과 한국어 제목·설명("엔터 키 설정").
